# Privacy Policy — Mobile Network Assistant

**Last updated:** October 2026

## 1. Overview

Mobile Network Assistant is a Windows desktop application developed by Bivon Maiko to help users inspect network information and troubleshoot connectivity issues.

## 2. Information Collection

The application performs network diagnostic tests on the user's computer, such as viewing local network information, checking connectivity, looking up DNS records, and testing TCP port availability.

The application is not designed to collect personal information for advertising or user profiling.

## 3. Network Activity

Some diagnostic features communicate with network devices, DNS servers, or internet hosts to perform requested tests. These connections may expose ordinary network metadata to the relevant systems.

## 4. Data Storage and Sharing

The application does not intentionally send diagnostic results to the developer for collection or analysis. Users should review their local configuration and any future integrations to understand whether additional data is stored or transmitted.

## 5. Security

Users should download the application from the official project repository and keep their operating system and security software updated.

## 6. Changes to This Policy

This policy may be updated if the application's features or data practices change.
