# Mobile Network Assistant

**Version 1.0.5** — A Windows desktop application for basic network diagnostics and troubleshooting.

## Features

- View local network information.
- Test network connectivity and reachability.
- Check TCP port availability.
- Use a simple graphical interface for network diagnostics.

## Technologies

- Python
- Flask
- HTML, CSS and JavaScript
- PyInstaller for Windows executable packaging

## Requirements

- Windows 10 or Windows 11 to run the packaged application.
- An active network connection for tests that require connectivity.

## Running the Application

### Windows executable

Download Mobile Network Assistant.exe from the project's GitHub Releases page and double-click it to launch.

### Run from source

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Install the required dependencies based on the application's imports.
5. Run server.py using Python.

The source version may require additional configuration and dependencies.

## Troubleshooting

- Check your network connection if a test fails.
- Firewalls may block certain connectivity tests.
- ICMP ping can fail even when HTTPS connectivity is available.
